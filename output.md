# My Desired Output

My Second Brain will produce a personalized and ranked collection of
information that can help me become a Full Stack/AI Developer and
secure a job by November 2026.

The output will be divided into five main categories:

 1. Job Opportunities

Information about:

* Full Stack Developer jobs
* AI Developer jobs
* Python Developer jobs
* Fresher and entry-level opportunities
* Relevant companies and hiring opportunities

The system should prioritize opportunities that match my current
skills and career goal.

2. Learning Resources

Useful resources related to:

* Python
* Full Stack Development
* Backend Development
* React and frontend technologies
* APIs and databases
* Generative AI
* LLMs
* AI development

Resources that directly improve the skills required for my target
roles should receive a higher priority.

 3. DSA and Interview Preparation

Information that helps me prepare for technical interviews, including:

* DSA problems and patterns
* Coding interview questions
* Python/Java interview concepts
* Computer Science fundamentals
* Technical interview strategies
* Frequently asked interview questions

This category supports my goal of completing 150+ DSA problems and
improving my placement preparation.

 4. Generative AI

Relevant information about:

* LLMs
* Generative AI tools
* AI frameworks
* RAG
* AI agents
* Prompt engineering
* LLM application development
* New techniques that can be applied to projects

The system should prioritize information that helps me understand
Generative AI deeply or build practical AI applications rather than
general AI news with no connection to my goal.

5. Projects and Portfolio

Information that can help me build stronger projects and improve my
portfolio, including:

* AI-powered project ideas
* Full Stack project ideas
* New development tools
* Open-source projects
* Useful APIs and frameworks
* Technologies that can improve my existing projects
* Ideas that combine Full Stack Development and Generative AI

# Final Output Format

For each relevant item, my Second Brain should provide:

* Title
* Source
* Category
* Relevance Score (1–10)
* Why it is relevant to my North Star
* Key information
* Recommended action

Example:

> Title: Python Full Stack Developer Job
> Source: LinkedIn
> Category: Job Opportunity
> Relevance Score: 10/10
> Why relevant: Directly matches my Full Stack Developer career goal.
> Recommended Action: Check eligibility and apply.
